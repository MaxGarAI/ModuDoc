# Docling RAG Telegram Bot

Интеллектуальный Telegram-бот с модульной архитектурой для анализа документов (PDF, DOCX, PPTX, TXT, MD), векторного поиска на базе **Docling** и **Pinecone** (индекс `pdf-bot`) и вопросно-ответной системы (RAG) через OpenRouter.

---

## 🚀 Возможности

1. **Обработка документов через Docling:**
   - Поддержка PDF, DOCX, PPTX, TXT, MD, HTML.
   - Извлечение структуры, заголовков, таблиц и метаданных.
   - Интеллектуальный чанкинг с помощью `Docling HybridChunker` с сохранением иерархии разделов.

2. **Векторная база Pinecone (индекс `pdf-bot`):**
   - Векторизация чанков через модель `openai/text-embedding-3-small` (1536 измерений, метрика косинусного сходства).
   - Сохранение метаданных (имя документа, номер страницы, цепочка заголовков, ID пользователя).
   - Изоляция данных между пользователями и возможность очистки истории (`/clear`).

3. **Автоматическое структурированное резюме:**
   - Сразу после загрузки файла бот генерирует саммари документа: основная тема, ключевые тезисы, важные выводы и примеры вопросов.

4. **Интеллектуальные ответы на вопросы (RAG):**
   - Поиск релевантных фрагментов по косинусному сходству.
   - Формирование ответа с цитированием первоисточников (название документа, страница, раздел).
   - Учет контекста предыдущих сообщений в рамках диалога.

## 📁 Структура проекта

```
Docling_RAG/
├── .env                              # Переменные окружения и ключи API
├── requirements.txt                  # Зависимости Python
├── run.py                            # Главная точка запуска Telegram-бота
│
├── src/
│   ├── config.py                     # Конфигурация и валидация переменных
│   │
│   ├── components/                   # Независимые модули
│   │   ├── document_parser.py        # Парсер документов на базе Docling DocumentConverter
│   │   ├── chunker.py                # Семантический чанкинг на базе Docling HybridChunker
│   │   ├── embedding_service.py      # Генерация векторов (OpenRouter 1536 dim)
│   │   ├── vector_store.py           # Операции с Pinecone (индекс pdf-bot)
│   │   └── llm_service.py            # Интеграция с LLM (резюме и ответы с цитированием)
│   │
│   ├── pipelines/                    # Оркестрирующие пайплайны
│   │   ├── ingestion_pipeline.py     # Загрузка -> Парсинг -> Чанкинг -> Индексация -> Резюме
│   │   └── rag_pipeline.py           # Вопрос -> Поиск в Pinecone -> Ответ LLM с источниками
│   │
│   ├── bot/                          # Telegram-интерфейс
│   │   ├── handlers.py               # Обработчики команд, документов и сообщений
│   │   └── bot.py                    # Инициализация и polling приложения
│   │
│   └── utils/                        # Вспомогательные утилиты
│       ├── file_storage.py           # Временные файлы и безопасная очистка
│       └── logger.py                 # Логирование
│
└── tests/
    └── test_pipeline.py              # Автоматический интеграционный тест полного цикла
```

## 🛠️ Запуск

### 1. Установка зависимостей
```bash
pip install -r requirements.txt
```

### 2. Настройка `.env`
Убедитесь, что в файле `.env` указаны необходимые ключи:
```ini
OPENROUTER_API_KEY=sk-or-v1-...
TELEGRAM_KEY=...
PINECONE_KEY=...
OPENAI_BASE_URL=https://openrouter.ai/api/v1
```

### 3. Проверка тестов
```bash
python tests/test_pipeline.py
```

### 4. Запуск бота
```bash
python run.py
```

## 💬 Команды бота в Telegram

- `/start` — Приветственное сообщение и краткое руководство.
- `/help` — Подробная справка по форматам и функционалу.
- `/status` — Проверка состояния индекса Pinecone и моделей.
- `/clear` — Удаление загруженных документов и векторов текущего пользователя из Pinecone.
- **Отправка документа** (PDF, DOCX, TXT и др.) — Автоматическая обработка и получение резюме.
- **Текстовое сообщение** — Вопрос по содержимому документов с указанием источников.
